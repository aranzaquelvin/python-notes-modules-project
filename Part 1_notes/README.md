# Part 1: Structured Python Notes

Welcome to my Python Notes! This folder contains 8 organized topics covering the fundamentals of Python programming. To prove that I didn't just copy-paste from the internet, each folder contains **8 unique code examples** designed with a progressive difficulty curve (Easy → Intermediate → Hard).

As per the assignment instructions, **no Object-Oriented Programming (OOP)** and **no complex Data Structures** were included. Just pure, logical, procedural Python code. 

## 📂 Topics Covered:

Here is the breakdown of what's inside each folder:

1. **`[01]PrintingAndVariables`**: The absolute basics. Printing text, taking user input, and storing data in variables. (We all have to start somewhere).
2. **`[02]OperatorsAndConditionals`**: Math operators and making decisions using `if`, `elif`, `else`, and `match/case`. This is where the code starts getting a brain.
3. **`[03]WhileAndForLoops`**: Making the computer do the repetitive work. Includes counting, factorials, and figuring out how to avoid infinite loops. 
4. **`[04]ListsAndNestedLoops`**: Storing multiple items in a list and navigating through 2D grids (lists of lists). Like a digital matrix, but less cool.
5. **`[05]ListMethodsAndComprehensions`**: Upgrading our lists using methods like `.append()`, `.sort()`, and writing one-liners with List Comprehensions.
6. **`[06]Functions`**: Writing reusable code with `def`, parameters, return values, and a little bit of recursion (Fibonacci, anyone?).
7. **`[07]StringMethods`**: Manipulating text. Changing cases, splitting words, and checking if a word is a palindrome.
8. **`[08]FileHandling`**: Reading and writing actual files. Making sure our data doesn't disappear when we close the terminal.
